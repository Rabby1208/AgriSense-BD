# AgriSense BD

বাংলাদেশের কৃষকদের জন্য বাংলা ভাষার, উৎসভিত্তিক কৃষি-সিদ্ধান্ত ও আবহাওয়া সতর্কতা ওয়েবসাইট।

## Features
Crop Advisory, Weather Dashboard, Weather Alerts, Daily Actions, Fertilizer Calculator, Irrigation Support, Pest & Disease Risk Guide, Weather History, Agricultural Bulletins, Crop Guide, Crop Plan (Print/PDF), Data Sources

## Technology
React (Vite), Node.js + Express, MySQL, Open-Meteo API
